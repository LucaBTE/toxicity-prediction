# ML Models Interpretability

This folder contains the centralized interpretability notebook for the classical
machine-learning models in `notebooks/ml-models`.

- `model_interpretability.ipynb`: loads or refits the ML models from their source
  notebook configurations and generates SHAP-based explanations.
- `outcome/figures/`: beeswarm and waterfall plots.
- `outcome/tables/`: SHAP summaries, local waterfall values, model-source table,
  prediction metrics, and cross-model feature overlap.

The folder name follows the requested spelling: `interpratability`.
